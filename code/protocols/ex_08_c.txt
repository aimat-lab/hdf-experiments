# ex_08_c -- Figure 3a (edit-based GED analysis) and Supplementary Section S9.1
# Paper: main-text Figure 3a (|Pearson r| between the number of edit steps and the distance to the seed molecule,
#   box plots over 100 ZINC250k seed molecules, Morgan radius 2 vs HDF depth 2, D = 32/128/512/2048) and its
#   description in Supplementary Section S9.1 (the per-step distance figure fig:ged_edit_steps is commented out in
#   the SI). Fig. 3b (KNN error ratio) is ex_29 (make_figure_knn_ratio.py), not this protocol.
# Source: graph_hdc revision/consolidated. HDF = the used job scripts _ex08c/jobs/ex_08_c__hdc__<D>.sh of the main
#   checkout (generator _slurm_ex_08c.py, commit 0f539e3; local SLURM jobs 4183-4186, 2026-10-09; archives
#   results/molecule_similarity__hdc/ex_08_c__*). Morgan and HDF with the original codebooks = the used job scripts
#   _ex08b/jobs/ex_08_b__{fp,hdc}__<D>.sh (generator _slurm_ex_08b.py, jobs 4027-4042, 2026-10-08; prefix ex_08_b).
#   The repro arm ex_08_b_repro (check against the original ex_08_a) is left out.
# Runs: 12 = 4 sizes x {HDF ex_08_c (paper), Morgan ex_08_b (paper), HDF ex_08_b original codebooks (needed by the analysis)}
# Protocol: ZINC250k, SEED 1; 100 seed molecules (GED_NUM_SAMPLES); from each, 20 molecules at each of 1, 2 and 3 edit
#   steps (vgd_counterfactuals get_neighborhood, NUM_HOPS 3, NUM_NEIGHBOR_BRANCHES 5, NUM_NEIGHBOR_TOTAL 20); the seed
#   SMILES is canonicalized (GED_CANONICAL_QUERY) so that all arms see identical pairs; per seed, Pearson r between
#   edit steps and distance (ged_pairs.csv, ged_correlation_summary.csv in each archive).
#   HDF (ex_08_c) = standard configuration: BIDIRECTIONAL True, HYDROGEN_COUNT 'total', SPECTRUM 'unit'; depth 2,
#   continuous encoders, cosine distance. Morgan: radius 2, binary, Tanimoto distance; Morgan was not re-run for
#   ex_08_c, since the pairs do not depend on the representation (analyze_ex_08c.py checks that they are identical).
#   HDF ex_08_b (SPECTRUM 'gaussian') is not in the paper, but analyze_ex_08c.py reads it (pair check, hdf_gaussian).
#   Every run also does the similarity search of the original ex_08 (NUM_SAMPLES 10 queries, 5 neighbours); unused.
# Analysis: python analyze_ex_08c.py   (-> _ex08c/analysis/: per_seed.csv, summary.csv = medians of Fig. 3a, pairs.csv,
#             pairs_deduplicated.csv, distances_per_step.csv, rebuild_check.csv; it re-encodes the pairs without the
#             size/diameter encodings and checks that the rebuilt HDF reproduces ex_08_c to 1e-5)
#           python make_figures_ged_edit.py   (-> figures/figure_ged_main_panel_a, ged_edit_per_seed,
#             ged_edit_distances_per_step (= the commented-out SI figure); the composite figure_ged_main_revised.pdf
#             only with $HDF_PAPER_DIR/figures/figure_ged_main.pdf (original Inkscape figure) and pdflatex)
# Cost: about 11 CPU-h (2 threads per run on euler): HDF 0.25 h (D=32) to 1.45 h (D=2048) per run, peak about 28 GB
#   RAM at D=2048 (keeps the embeddings of all ~250k ZINC250k molecules; the jobs requested 24/40 GB); Morgan < 0.1 h.
# Notes: needs vgd_counterfactuals (installed in the Dockerfile) and ZINC250k from chem_mat_data, which
#   molecule_similarity.py downloads to /tmp: download it once before running the lines in parallel (the scheduler
#   pre-loaded it). Stripped from the job scripts: cd, TMPDIR, OMP/MKL_NUM_THREADS=2, CUDA_VISIBLE_DEVICES=, git logging.
#   The ex_08_b HDF job scripts (2026-10-08) predate the SPECTRUM parameter (added 2026-10-09 with the unit-modulus
#   default): --SPECTRUM="'gaussian'" is added here, as _slurm_ex_08b.py now writes it; without it the capsule
#   default 'unit' would duplicate ex_08_c (and DATASET_NAME_ID is the same for both HDF prefixes; caching is off).
