# ex_11_b -- virtual screening re-run (Supplementary Section S6.2, Supplementary Figure S2a)
# Paper: SI Section S6.2 (similarity-based virtual screening: ROC-AUC, EF1%, Wilcoxon over targets) and
#   Supplementary Figure S2a (bars of ROC-AUC and EF1% for Morgan, HDF and HDF without size/diameter).
# Source: graph_hdc revision/consolidated, generator _slurm_ex_11b.py; the lines are the used run scripts
#   _ex11b/jobs/ex_11_b__<arm>__<dataset>.sh of the worktree graph_hdc/.claude/worktrees/ex11b (SLURM chains
#   4294-4296 on euler, 2026-10-13; 12 archives results/predict_bioactivity__{hdc,fp}/ex_11_b__*). The original runs
#   (prefix ex_11_bioact, original encoder) are no longer used in the paper.
# Runs: 12 (4 benchmarks x 3 arms)
# Protocol: Riniker 1, Riniker 2, MUV and DUD-E (from chem_mat_data); targets with >= 10 actives; per target 50
#   repetitions (NUM_REPETITIONS) of 5 random query actives (SEED 1); each query ranks all other actives and decoys by
#   its similarity to them; ROC-AUC, BEDROC (alpha 20), EF1% and EF5% are averaged over the queries and repetitions,
#   then over the targets. Arms: HDF without the size/diameter encodings (GRAPH_ATTRIBUTES False, the main HDF arm of the SI),
#   Morgan ECFP4 (radius 2, 2048 bits, binary, Tanimoto; re-run unchanged, reproduces ex_11 exactly), HDF with
#   size/diameter (GRAPH_ATTRIBUTES True, the standard HDF). Both HDF arms: D 2048, depth 2, continuous, cosine,
#   BIDIRECTIONAL True, HYDROGEN_COUNT 'total', SPECTRUM 'unit' (passed explicitly).
# Analysis: python analyze_ex_11b.py   (-> _ex11b/analysis/summary.csv|md, paired.md (HDF vs Morgan per target,
#             two-sided Wilcoxon), morgan_reproduction.md (only if the original ex_11_bioact archives exist))
#           python make_figure_ged.py   (-> figures/figure_ged.pdf = Supplementary Figure S2; panel a from the ex_11_b
#             archives with NUM_REPETITIONS 50, panel b from _ex22/ged_arms_trimmed_zinc250k.csv of ex_17.txt;
#             --draft allows missing runs)
# Cost: about 60 CPU-h on euler (2026-10-13): HDF 0.5 h (Riniker 2) to 3.4 h (DUD-E, ~400k molecules) per run at 4
#   threads (~13.5 run-hours), Morgan 0.4-1.2 h at 2 threads; peak memory 15-20 GB per HDF run on DUD-E (14 GB Morgan).
# Notes: pre-fill the chem_mat_data cache one dataset at a time before running lines in parallel (concurrent first
#   downloads can corrupt it). predict_bioactivity.py downloads into tempfile.gettempdir()/chem_mat_<dataset> and
#   deletes that folder first, so parallel runs on the same dataset need separate TMPDIRs (the run scripts set a private
#   TMPDIR per run; stripped here together with cd, PYTHONPATH (worktree), OMP/MKL threads, CUDA_VISIBLE_DEVICES= and
#   git logging). Both HDF arms share DATASET_NAME_ID (<dataset>_bioact_hdc); caching is off. Only 26 of the 102 DUD-E
#   targets carry labels in the dataset. The runs ran in three sequential chains because of the memory on euler.
