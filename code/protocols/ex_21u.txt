# ex_21u -- Stereochemistry: Supplementary Section S13, Tables S13 and S14 (optional HDF stereo attribute)
# Paper: Supplementary Section S13; Table S13 (ZINC250k collisions, part collisions), Table S14 (ChIRo docking ranking,
#        part chiro; CMRT elution order on the authors' split and on random splits, part cmrt). Parts bace and props
#        (BACE, FreeSolv, AqSolDB property prediction with/without stereo) belong to the same round but are not
#        reported in the SI (supporting runs for the "default off" decision; summarized by analyze_ex_21.py).
#        No reviewer asked for this; not cited in the response letter beyond the opening reply.
# Source: job scripts of the used run, graph_hdc worktree stereo (branch revision/stereo, commit 64f05f2; HEAD ec7e95e
#         changes only analyze_ex_21.py), _ex21/jobs/ex_21u_*.sh (63 scripts): python lines only (env exports, cd,
#         TMPDIR, git/echo lines stripped). Cross-checked: identical (as a multiset) to the lines that _slurm_ex_21.py
#         groups("ex_21u") writes in a scratch copy of 64f05f2. Order here = that of the scheduler.
#         The absolute CSV paths <repo>/data/... were replaced by ../../../data/..., which is where prepare_*.py write
#         (REPO = this folder/../../..). Earlier round ex_21 (gaussian codebooks, no Morgan arms) not included.
# Runs: 248 = prepare 2 + collisions 4 + bace 50 + chiro 12 + props 100 + cmrt 80
#   collisions: 2 arms x D 256/2048; chiro: 3 seeds x (HDF plain, HDF stereo, Morgan, Morgan chiral);
#   cmrt: (given split, random 194-pair splits) x 10 seeds x 4 arms; bace: 10 seeds x 5 runs; props: 2 datasets x 10 x 5
#   (5 runs = HDF plain, HDF stereo, HDF plain re-seeded with NN_SEED 1000+seed, Morgan, Morgan chiral).
# Protocol: HDF in the ex_14 configuration (D 2048, L 2, unit codebooks, bidirectional, total H; MLP (100,100) lr 1e-3
#   + KNN k=5) without/with STEREO (CIP labels R/S, r/s, E/Z bound into the node HVs); binary Morgan 2048 bits r2
#   without/with FINGERPRINT_CHIRALITY (RDKit includeChirality), same splits and models. Caching disabled in all runs.
#   Collisions: ZINC250k with stereoisomers as distinct molecules (DEDUPLICATION isomeric; MORGAN_CHIRALITY = STEREO).
#   ChIRo: original splits of Adams et al.; ranking accuracy of the docking scores, ties count half.
#   CMRT: first-eluted label (1/0) regressed, accuracy at threshold 0.5 and pair ranking accuracy.
# Analysis: python analyze_ex_21.py   (default prefix ex_21u; -> _ex21/summary_ex_21u.md with all five parts,
#   incl. the number of test pairs with identical representations)
# Cost: CPU only (2 threads, 4 CPUs per job; memory 24 GB collisions, 16 GB chiro, 10 GB bace/props/cmrt); ~21 run-h
#   in total; longest runs: ZINC250k collisions ~2.6 h, ChIRo HDF ~0.8 h.
# Notes: EXTERNAL DATA (stage prepare, needs network): prepare_chiro_docking.py downloads the three ChIRo split pickles

#   ../../../data/chiro_docking/chiro_docking.csv; prepare_cmrt_elution.py downloads RF_models/class_all.csv of
#   Baimacheva et al. (GitHub jairesdesousa/chiraldlsv; CMRT subset of Xu et al. 2023) and writes
#   ../../../data/cmrt_elution/cmrt_adh.csv. On Code Ocean ../../../data is /data (read-only during a run): provide
#   both CSVs there beforehand or pass other PAIRS_CSV / CHIRO_CSV paths. ZINC250k, BACE, FreeSolv and AqSolDB come
#   from chem_mat_data; the used run pre-loaded them and gave every job a private TMPDIR (chem_mat_data rewrites a
#   metadata file in the temp folder), so pre-load them or isolate TMPDIR when running lines in parallel.
