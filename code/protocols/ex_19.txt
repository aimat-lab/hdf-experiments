# Paper: Supplementary Section S11, Table S11 (MLP); hyperparameters in Supplementary Table S16.
#        The HDF column of Table S11 is NOT run here: it is the HDF + MLP result of ex_14 (prefix ex_14_gnn, round 4,
#        SPECTRUM unit); analyze_ex_19.py reads those archives and checks that every fingerprint run used the same split.
# Source: graph_hdc revision/consolidated (9eaaa27), regenerated with _slurm_ex_19.py in a scratch copy; prefix
#         ex_19_fp. Identical to the used file _ex19/ex19_commands.txt (graph_hdc main checkout, 2026-10-09; KCIST job
#         51065) except the 50 hopv15_pce lines, whose TARGET_INDEX is 3 (real PCE) instead of 5 (a band gap); those
#         were re-run on 2026-10-13 under the same prefix (_slurm_fix_targets.py, KCIST job 51196).
# Runs: 457 = warmup 7 (the ex_14 warmup lines, prefix ex_14_warmup; skip if ex_14 already ran in
#   this folder) + main 450 (9 targets x 5 fingerprints x 10 seeds)
# Protocol: the 9 ex_14 targets and seeds 0-9 on the ex_14 splits (caching left on, so the cached load__ dataset order
#   of ex_14 fixes the splits). 2048 positions each: Morgan r2 (hash-folded), SECFP r3 (folded MHFP6), MAP4 r2 (folded),
#   Sort & Slice ECFP4 (2048 most frequent training substructures), Sherlock (2048 highest-entropy substructures of
#   radius <= 6). The Sort & Slice and Sherlock vocabularies are fitted on the training split of every run, without
#   labels. Downstream: the ex_14 MLP only ((100,100), lr 1e-3; no KNN).
# Analysis: python analyze_ex_19.py   (needs the ex_14 HDF archives in results/; -> _ex19/results_ex_19_fp.csv and
#   _ex19/fp_comparison_mlp_ex_19_fp.tex = Table S11; split mismatches against ex_14 are printed)
# Cost: CPU only; ~450 runs in one KCIST job (4 array tasks, 8 h limit). MAP4 and Sherlock (SHERLOCK_FIT_JOBS 4) on
#   QM9 are the longest runs (the file is sorted longest first).
# Notes: no external data. Sherlock runs with SHERLOCK_DICTIONARY_PATH None, i.e. the vocabulary is fitted on each
#   training split (user decision 2026-10-09); the COCONUT+LOTUS dictionary of graph_hdc data/sherlock (fit_sherlock.py)
#   is NOT used by the paper, so the "falling back to fitting on the training split" warning in the log is expected.
#   SECFP and MAP4 need the mhfp package (graph_hdc/baselines/minhash_fps.py imports mhfp.encoder; the MAP4 shingling is
#   vendored there, so the map4 package is not needed). mhfp 1.9.6 is installed with --no-deps (environment/Dockerfile).
#   Requires the ex_14 warmup caches (same .cache folder) for identical splits.
