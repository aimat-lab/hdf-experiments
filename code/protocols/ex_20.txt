# ex_20 -- bit-depth ablation of HDF (reviewer comment R2.2), round ex_20_bits_unit
# Paper: Supplementary Section S8, Supplementary Figure S5 (fig:bits_ablation)
# Source: the used group scripts _ex20/jobs_worktree_run_unit/ex_20_bits_unit__<target>__seed_<k>.sh of the graph_hdc
#         main checkout (written by _slurm_ex_20.py --round ex_20_bits_unit, graph_hdc ec220f6, euler SLURM jobs
#         4187-4216, 2026-10-10); only the python lines were kept (env exports, cd, TMPDIR, PYTHONPATH and the
#         import/git checks stripped); the smoke script is excluded. Prefix ex_20_bits_unit.
# Runs: main 210
#       = 3 targets (FreeSolv, AqSolDB, BACE) x 10 seeds x 7 runs (float32, 16, 8, 4, 2, 1 bits per dimension, and
#       float32 with NN_SEED = 1000 + seed as the run-to-run reference)
# Protocol: HDF 2048 dims, depth 2, bidirectional, total H, unit-modulus codebooks (SPECTRUM unit), codebook per seed;
#   equal-frequency quantization fitted on the training split (QUANTIZE_BITS); MLP neural_net2 (100,100), lr 1e-3;
#   seeds 0-9; CPU only; caching disabled (__CACHING__ False), so the lines share no cache files. The KN_* parameters
#   are inert (MODELS = neural_net2 only).
# Analysis: python analyze_ex_20.py ex_20_bits_unit --out figure_bits.pdf   (-> _ex20/bits_ex_20_bits_unit.csv/.md and
#           the box plot of the MAE relative to float32 per bit depth = Fig. S5)
# Cost: ~1 h on euler with 30 jobs of 4 CPUs / 2 threads (each job = one target x seed, its 7 runs in sequence);
#   ~30-60 core-hours.
# Notes: the SLURM script ran the 7 runs of a (target, seed) one after the other; they are independent and may run in
#   parallel. Datasets via chem_mat_data (freesolv, aqsoldb, bace_reg; pre-downloaded in the paper).
