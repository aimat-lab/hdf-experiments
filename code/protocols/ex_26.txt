# Paper: not reported in the manuscript or the SI. Background for the response letter (opening reply: logP "could easily
#        be added as a further global attribute"); the user decided (2026-10-13) to keep that sentence without citing
#        ex_26. Report: graph_hdc experiments/fingerprints/EX26_CLOGP_GLOBAL_ATTRIBUTE.md (branch revision/ex26-clogp).
# Source: graph_hdc revision/consolidated (9eaaa27), regenerated with _slurm_ex_26.py in a scratch copy (identical to
#         the ex26clogp worktree version; its smoke file matches the used _ex26/smoke_hdf.txt); prefix ex_26_clogp.
#         Every line is the ex_14 round-4 HDF line with --GRAPH_CLOGP="True" appended (checked).

#   + hdf 20 (9 targets x 10 seeds)

#   the RDKit Crippen logP of the molecule encoded like the graph size (fractional power encoding, bandwidth =
#   (p99 - p1 of the dataset logP) / 7, min 1) and added to the graph HV. Baseline = the ex_14 HDF runs, paired by
#   target and seed on identical splits.
# Analysis: python analyze_ex_26.py   (needs the ex_14 round-4 HDF archives in results/; -> _ex26/results_ex_26_clogp.csv
#   and _ex26/summary_ex_26_clogp.md: paired Wilcoxon per target, Holm over the 9 targets)
